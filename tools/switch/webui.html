供应商 / 模型切换

切换 = 探活 → 落盘 → 重启。Claude Code 只在启动时读一次配置，所以每次切换都会真的结束并重启会话，不是只改文件。
「切换」按钮只动飞书那端，不碰你自己的终端——要连终端一起换，切换完会另给一个明确的按钮。
让飞书端跟你本机（终端）完全一致：整份覆盖，第三方连 Base URL 和 Key 一起搬，官方订阅则搬成官方直连 （不用重新登录，走你已登录的凭据）。覆盖后自动重启桥接会话。
两端默认互不干涉——桥接首次启动不会从本机拷任何配置，只有点这里才复制。
